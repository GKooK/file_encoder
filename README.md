# zipx — 비밀번호로 잠그는 압축 도구

파이썬 **표준 라이브러리만으로** 동작하는 단일 파일(`zipx.py`) 명령줄 프로그램입니다.
압축 파일과 이 소스 코드가 함께 유출되어도, 비밀번호를 모르면 내용을 알 수 없도록
만드는 것이 목표입니다.

```bash
./zipx.py c 자료.zipx 문서폴더       # 압축 (비밀번호를 물어봅니다)
./zipx.py x 자료.zipx -d 풀기        # 해제
./zipx.py l 자료.zipx                # 목록 보기
./zipx.py t 자료.zipx                # 무결성 검사
```

`zipx.py` 파일 하나만 복사하면 어디서든 동작합니다. 설치할 패키지는 없습니다.

## 해제 전용 `unzipx.py`

압축 파일을 남에게 보낼 때 같이 건네주는 용도의 **해제 전용** 프로그램입니다.
이 파일 하나만 있으면 풀 수 있고, 압축(만들기) 기능은 들어 있지 않습니다.

```bash
./unzipx.py 자료.zipx                 # 현재 폴더에 풀기
./unzipx.py 자료.zipx -d 풀어낼폴더
./unzipx.py 자료.zipx -l              # 풀지 않고 목록만 보기
./unzipx.py 자료.zipx -t              # 무결성 검사만
```

`zipx.py` 없이 단독으로 동작하며, 만들어내는 결과는 `zipx.py x` 와 완전히 같습니다.

## 동작 방식

압축한 ZIP **전체**를 아래처럼 한 겹 감쌉니다.

```
scrypt(비밀번호, salt) → 키 64바이트 ┬→ 앞 32B: AES-256-CTR 암호화 키
                                     └→ 뒤 32B: HMAC-SHA256 인증 키

매직(8) │ KDF파라미터(4) │ salt(16) │ IV(16) │ 헤더태그(16) │ 암호문 … │ HMAC-SHA256(32)
```

* **파일 이름과 폴더 구조까지 암호문 안에** 들어갑니다. 바깥에서 알 수 있는 건 전체 크기뿐입니다.
  (표준 ZIP 암호화는 내용만 가리고 파일 이름은 그대로 노출됩니다.)
* **Encrypt-then-MAC** — 복호화 전에 인증 태그를 먼저 확인하므로, 한 바이트라도 조작되거나
  잘려 있으면 해제를 거부합니다.
* **헤더 태그** 덕분에 비밀번호가 틀리면 전체를 읽지 않고 즉시 판별합니다.
* salt 와 IV 는 압축할 때마다 새로 만들어지므로, 같은 내용을 같은 비밀번호로 압축해도
  결과 파일은 매번 완전히 달라집니다.
* 결과 파일은 소유자만 읽을 수 있는 권한(0600)으로 생성됩니다.
* 해제할 때 `../` 가 들어간 경로는 대상 폴더 안으로 정규화합니다 (Zip Slip 방지).

AES 는 표준 라이브러리에 없어 직접 구현했습니다(FIPS-197 시험 벡터로 검증).
`pycryptodome` 이나 `cryptography` 가 **이미 설치되어 있으면** 그 C 구현을 자동으로 빌려 써서
훨씬 빨라지고, 없으면 순수 파이썬 구현으로 그대로 동작합니다. 어느 쪽이든 결과 파일은 동일합니다.

## 키 유도 강도

`--kdf` 로 조절합니다. 비용이 클수록 정상 사용자도 그만큼 기다리지만,
비밀번호 대입 공격도 똑같은 배수로 느려집니다.

| 강도 | scrypt 파라미터 | 메모리 | 시도 1회당(참고) |
|---|---|---|---|
| `normal` | N=2^16, r=8, p=1 | 64 MiB | 약 0.2초 |
| `high` (기본) | N=2^18, r=8, p=1 | 256 MiB | 약 0.7초 |
| `extreme` | N=2^20, r=8, p=1 | 1 GiB | 약 3초 |

메모리를 많이 쓰는 방식(memory-hard)이라 GPU 로 병렬 대입하기 어렵습니다.

## 명령어

| 명령 | 설명 |
|---|---|
| `c`, `compress` | `zipx.py c <만들 파일> <대상...> [--kdf 강도] [-l 0-9] [-o]` |
| `x`, `extract` | `zipx.py x <압축 파일> [-d 대상폴더]` |
| `l`, `list` | `zipx.py l <압축 파일>` |
| `t`, `test` | `zipx.py t <압축 파일>` |

공통 옵션: `-p 비밀번호` (생략하면 화면에 보이지 않게 입력받음), `-q` (진행 표시 끄기).

## 파이썬에서 쓰기

```python
import zipx

zipx.create("자료.zipx", ["문서폴더"], "비밀번호", kdf="high")
zipx.extract("자료.zipx", "풀기", "비밀번호")

for info in zipx.listing("자료.zipx", "비밀번호"):
    print(info.filename, info.file_size)

print(zipx.test("자료.zipx", "비밀번호"))     # {'checked': 12, 'broken': []}
```

진행률이 필요하면 `progress=콜백` 을 넘깁니다. 콜백은 `(처리한 바이트, 전체, 파일명)` 을 받습니다.

## 구성

```
zipx.py              프로그램 본체 (AES → CTR 스트림 → 컨테이너 → 압축/해제 → 명령줄)
unzipx.py            해제 전용 배포판 (단독 동작, 압축 기능 없음)
tests/test_zipx.py   테스트
```

## 유의할 점

* 이 형식은 이 프로그램 전용입니다. 7-Zip·반디집·윈도우 탐색기에서는 열리지 않습니다.
* 비밀번호를 잃어버리면 복구할 방법이 없습니다.
* 명령줄에 `-p 비밀번호` 를 직접 쓰면 셸 기록에 남습니다. 되도록 `-p` 없이 실행해
  입력 프롬프트를 쓰세요.
